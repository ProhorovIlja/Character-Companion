# On-demand Wikipedia research

Roleplay Toolkit and the existing research editor now offer a native Wikipedia lookup with explicit EN/RU/SV language selection. One fixed HTTPS GET per user action, public MediaWiki search generator + TextExtracts, at most five results, 64 KiB decoded response cap, strict UTF-8, depth check, 8-second connection/read timeouts and cooperative 20-second read deadline (not a hard total deadline). No redirects, retry, cache, API key, renderer cookie access or automatic sending. The query and connection metadata are disclosed to Wikipedia. Results are plain text and selected individually (unchecked by default), with source page URLs and attribution/license text. The selected packet can be appended to the existing research editor without replacing it or copied via the normal context preview. External information is not guaranteed correct and its label does not guarantee prompt-injection protection. Existing context budget still applies. The standalone action starts with research only; combined memory context can use the same button from its research editor.

Verified design references: https://www.mediawiki.org/wiki/API:Search ; https://www.mediawiki.org/wiki/Extension:TextExtracts ; https://www.mediawiki.org/wiki/API:Etiquette/en ; https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy/en ; https://docs.sillytavern.app/extensions/websearch/ . No upstream code copied. No new dependencies or permissions. 34 focused Kotlin/JVM checks and 26 existing context checks executed for pure code. Android JSON parser, live Wikimedia endpoint, UI, complete Python suite, compilation and device tests not executed. Not a general web crawler, autonomous character search or server-limit bypass.
