# Material-inspired AMOLED shell

Retain the existing Android Views and both rendering engines. Add shared surface, text, accent, disabled and ripple tokens; OLED chrome/background stays true black while cards and controls have near-black surfaces. Standard native buttons inherit rounded 16 dp state-aware backgrounds, 48 dp minimum height/width, mixed-case medium typography. Preserve the 52 dp header, 56 dp footer, four actions and keyboard/compact visibility behavior. Navigation receives bounded platform ripple; Gecko back drawable uses RTL-aware placement. Five Google Material Symbols Rounded SVG paths converted to 24 dp vector drawables (no font, raster library or runtime asset fetch). Apache-2.0 text and original blob hashes included in app assets. No new dependency or permission. Platform ripple only, no custom animation loop, no claims about FPS, battery or latency without device measurements. This is a native shell design pass, not a complete Material 3 migration or website restyling. Existing hardcoded colors and dialog/renderer-specific layouts still need follow-up. Test on device with large font, TalkBack, RTL and both engines.

Sources: https://developers.google.com/fonts/docs/material_symbols ; https://github.com/google/material-design-icons ; https://developer.android.com/design/ui/mobile/guides/foundations/accessibility ; https://developer.android.com/training/material/animations.html ; https://developer.android.com/develop/ui/compose/designsystems/material3 .
