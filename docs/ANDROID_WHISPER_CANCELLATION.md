# Mandy AI — cooperative embedded speech cancellation and constant-signal rejection

This increment extends the standalone speech bridge from ANDROID_EMBEDDED_WHISPER.md. The pinned upstream whisper.h exposes encoder_begin_callback and abort_callback; the new V2 JNI signature supplies both. Native cancellation checkpoints also run before model initialization, after initialization, during PCM conversion and before/after full recognition and segment extraction. The Kotlin call still validates the model digest and cancellation before/after native execution. The caller must provide a fast, nonblocking cancellation predicate and own stable PCM/model inputs. A reentrant recognition attempt is refused.

Threading decision: JNIEnv and local jobject references are thread-affine. Only the original invoking JVM thread polls the Kotlin cancellation predicate. Backend worker callbacks may read an atomic latched cancellation flag, but do not invoke Java or attach threads. This avoids using an invalid JNIEnv and avoids callback threads entering the synchronized Kotlin engine. This is cooperative cancellation, not a hard deadline: upstream callbacks may be invoked on workers only or may not be invoked promptly during computation or model loading. A worker-only interval cannot observe a new Kotlin cancellation until an owner-thread checkpoint. Real cancellation latency and support are unverified. No timers, worker creation by production code, monitoring, scheduled operations or background activity. No partial transcript is returned on a cancelled call. Rebuild Kotlin and native binaries together; export symbol and R8 keep rules updated.

A lightweight precheck rejects entirely constant PCM buffers (including digital zeros, DC offset and one-sample buffers) before hashing/loading the model. It stops scanning when variation is found and checks cancellation at 4096-sample intervals. This is not VAD, noise suppression, speech detection or a guarantee against hallucinations. Noise and nonconstant silent recordings may pass, and no arbitrary quiet-speech energy threshold is applied. Use a validated bilingual VAD and compare quiet-speech false-rejection rates before introducing a stronger filter. No automatic send integration.

Tests exercise constant PCM refusal, owner-thread callback restriction, cancellation at every observed checkpoint, recovery after cancellation and reentrant rejection, plus prior multilingual/hash/PCM/output checks. Exact four compiled source blob hashes checked before commit. The test-only backend is not a speech model and never ships in production. The CMake/Gradle/Android SDK/NDK build and actual model execution have not been verified; R8 rules are source changes only. No APK, EXE, Windows change, new library or model weights. No actual speech-quality or hardware latency claim.
