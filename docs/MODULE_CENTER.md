# Built-in module center

The Modules command in all three renderer modes opens a private native activity with thirteen typed destinations grouped into Character creation, Memory and knowledge, and Utilities and help. Search matches localized labels and stable English identifiers; it runs only on the small in-memory catalog. Existing editors, stores, backup format, search client and free-help actions are reused. No web renderer is created by this activity, no data migration, no dynamic code loading, no extra dependencies, permissions or background tasks. The selected theme, 48 dp minimum actions, RTL padding, native ripple, system bar/IME insets and accessibility headings apply. Only the module-search query is saved in instance state. Existing nested dialogs still require further UX work and device testing. This is a navigation/module registry, not a Gradle multi-module split or external plugin marketplace.

Design references: https://docs.sillytavern.app/extensions/ and https://developer.android.com/guide/topics/ui/accessibility/views/apps-views and https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns . No upstream code copied.

## Pinned modules and utility integration
The catalog now contains fifteen entries, including the existing voice draft and manual GitHub Release Center. Voice opened from this renderer-independent screen is copy/export only, without a focused-editor insertion ticket; the chat's existing Voice action is unchanged. Explicit pins persist as stable enum names in a separate local preference file. Unknown names are ignored and pinned modules are displayed once above their original groups; search applies to both. No runtime module downloads, automatic update checks or new dependencies. Native checkbox states and accessible labels expose the pin action. Rebuilding the small list on pin changes may reset focus/scroll; device testing remains necessary. Thirty pure Kotlin catalog assertions passed locally; Android compile and full suite remain unverified.
