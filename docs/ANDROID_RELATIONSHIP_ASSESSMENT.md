# Mandy AI — evidence-bound relationship assessment

Adds RelationshipAssessment, a foreground-only model proposal API and experimental Android review action. A proposal uses the latest completed reply and its deterministic matching user message from the exact conversation, together with reviewed prior relationship state. It does not use message count as a progression signal. The model can return UNCHANGED or one of the seven existing stage names and a concise note. Unknown stages, malformed output, missing completed evidence, excessive evidence and cancellation fail closed. There is no compulsory linear or romantic progression. Approval revalidates exact evidence and current memory revision; the character's pinned and other memories are preserved.

The experimental workspace exposes Review relationship from dialogue after a completed reply, when a model is available. The user selects and confirms trust of a local model, runs a separate synchronous generation on the existing worker, and reviews proposed stage, note and the actual supporting dialogue before approving or rejecting. Stop and leaving the workspace request cooperative cancellation. No network fallback, auto-escalation, scheduled or background assessment. Approval is optional and explicit; the existing manual editor remains available. The proposal is not persisted and this is not an append-only evidence audit log. Repeated assessments of the same evidence after an accepted revision are possible; the model's semantic interpretation is not guaranteed. The 200-row search, 6000 UTF-16 evidence limit and 384 generation tokens are provisional. This uses a model prompt rather than a formally secure untrusted-data boundary. Current state writes rely on the existing serialized worker; no cross-process transactional guarantee.

Validation: the exact RelationshipAssessment.kt and RelationshipAssessmentSmoke.kt were compiled on JVM with the existing native history, workspace and memory classes and passed 18 counted assertions. Real temporary memory files and an in-memory history/model fixture were used. Tested empty and incomplete dialogue, evidence binding, unchanged output, malformed outputs, cancellation, explicit approval, character isolation, persisted accepted state, stale revision and changed evidence. Android UI source and host-script changes have not been run on Android; no real LLM assessment or APK/EXE. Android SDK/NDK and real upstream build remain outstanding. This change does not create or dispatch a workflow.
