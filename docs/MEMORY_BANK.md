# Character memory bank

Separate user-named profiles with topic/body records; 96 total entries, 2,000 UTF-16 units per body, 6,000-unit recall budget. Profile and title keys use NFKC/case folding and trim; profiles are labels, not authenticated character/chat IDs. Exact Unicode word matching, title weight 3 and body weight 1, recent edits break ties. Entire records fit or are omitted; counts shown. Users manually add/edit/delete and review/copy recalled context through the existing Context Builder. No automatic extraction, embedding model, network, chat API or scheduled action. AtomicFile in noBackupFilesDir with optimistic compare-before-save and readback; private OS storage, not independent encryption or portable backup. Synchronous bounded local IO and ranking in dialog handlers still require device latency testing. Existing roleplay slots remain untouched. Full Android compile and runtime tests not done; 29 pure Kotlin checks executed locally, structural Python tests added but not run.

Design references: SillyTavern Data Bank and World Info (https://github.com/SillyTavern/SillyTavern-Docs/blob/main/Usage/Characters/data-bank.md ; https://docs.sillytavern.app/usage/core-concepts/worldinfo/), CharMemory retrieval (https://github.com/bal-spec/sillytavern-character-memory/blob/master/docs/retrieval-and-prompts.md), MemoryBooks (https://github.com/aikohanasaki/SillyTavern-MemoryBooks), Character.AI free pinned memories (https://support.character.ai/hc/en-us/articles/24327914463003-Pinned-Memories), community recap strategies (https://www.reddit.com/r/CharacterAI/comments/1g3vwso). No external code copied. Lexical recall is not semantic RAG or model training.
