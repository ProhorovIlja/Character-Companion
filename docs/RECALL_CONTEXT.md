# Combined character context
Memory Bank recall now opens a user-reviewed list of matching records (initially selected, can deselect). Selection is validated against one named profile, and the existing 6,000 UTF-16 recall cap. The optional shared Persona, Scene and Prompt slots are unchecked by default, and the global Memory slot is excluded. Research text can then be pasted into the existing context editor, with complete 16,000 UTF-16 packet validation and manual review/copy. Oversized data is rejected without truncation. No network call, automatic send, server quota change, model training or persistent task.
