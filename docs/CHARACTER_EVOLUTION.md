# Character evolution (reviewed local state)

Five profile-scoped fields stored as ordinary Memory Bank records with fixed English titles prefixed "Evolution / ": core identity, acquired development, relationships, interests and goals, current situation. No new file format or migration; memory backup already includes these records. Existing entries with these exact normalized titles are treated as state, shown before editing. Explicit saves update one field using the existing optimistic store guard; ordinary memories remain independent. Each field consumes one of the 96 total records and has the existing 2,000 UTF-16 limit. The user can remove a field through Memory Bank. The evolution packet combines recorded state with guidance to keep identity consistent, respond to the actual topic, vary initiative, avoid forcing any single topic, and distinguish temporary moods from lasting change.

Review conversation accepts a manually pasted excerpt up to 8,000 UTF-16 units (combined prompt up to 16,000). It generates a prompt for a separately chosen AI model to propose grounded changes, not an actual summarizer or learning engine. The user reviews the response and manually updates the state or records an event. No automatic capture, extraction, remote write, send, model training, account-ID binding or scheduled activity. Existing knowledge/context and search features remain available separately. No voice/audio integration in this change.
