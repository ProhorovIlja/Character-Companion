NativeModelLibrary copies an explicitly selected GGUF byte stream into private storage using a 128 KiB buffer, preliminary little-endian GGUF v2/v3 header validation, optional expected byte count and SHA-256, file sync and same-directory atomic publication. Identical imports reuse the existing verified file. Failed imports remove staging files when the process is alive. Verification rehashes before engine use; a computed digest without a trusted expected digest is not publisher authentication. The preliminary header check does not validate tensor data, architecture, license, model quality or compatibility. The synthetic tests are not real GGUF models. 8 GiB per-file provisional limit, not a memory budget; no total library quota, deletion, interrupted-process staging cleanup, multi-process locking or power-loss guarantee. Known-size import checks free space; unknown size relies on file I/O errors and per-file cap.
