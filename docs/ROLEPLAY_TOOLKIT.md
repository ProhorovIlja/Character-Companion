# Local roleplay toolkit
Community references: CAI Tools offers dice, memory tools, greeting management and appearance options (https://chromewebstore.google.com/detail/cai-tools/nbhhncgkhacdaaccjbbadkpdiljedlje and https://irsat.gitbook.io/cai-tools/features/features). Greasy Fork lists navigation, chat styling and translation scripts (https://greasyfork.org/en/scripts/by-site/character.ai). Morse documents local export (https://github.com/trymorse/character-ai-exporter). Official account export: https://support.character.ai/hc/en-us/articles/56967715028891-How-do-I-download-my-data . Official pinned memory: https://support.character.ai/hc/en-us/articles/24327914463003-Pinned-Memories . Community reports mention refreshing stalled chats: https://www.reddit.com/r/CharacterAI/comments/1wxnikf/is_it_just_me_lagging_on_web_and_app_and_have_to/ . CAI Tools guide warns a character-only URL can reopen the newest chat, so do not promise exact conversation restoration without a conversation identifier.
Implemented: four independent explicit local text slots (one each for Persona, Scene, Chat memory and Message template), each up to 16,000 UTF-16 units, strict versioned CCRP encoding, bounded UTF-8 and EOF checks, Android AtomicFile with readback, private noBackupFilesDir, user-operated save/copy/reset, sensitive clipboard marker, no keyboard learning request, dice d4/d6/d8/d10/d12/d20/d100 with 1–10 dice and copyable total. Available in all three modes. No automatic insertion, account sync, browser script, remote memory limit changes or server retries. No new dependencies or permissions. The UI uses native dialogs and small synchronous local file operations; device latency and configuration changes not tested. Unconfirmed text may be lost on dismissal/recreation; local files are not encrypted beyond OS protection and are not a portable backup. Official free Slow Mode remains service-controlled; this does not bypass it.
31 JVM assertions actually executed using exact RoleplayToolkit.kt and RoleplayToolkitSmoke.kt; Android UI, AtomicFile integration, complete repository suite and APK build not executed. Source-level Python integration tests added.
