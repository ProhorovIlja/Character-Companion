# Responsive local editors

Roleplay slot loads, saves, resets, selected context reads, memory bank loads, writes, deletion and lexical recall run as single user-initiated operations off the UI thread. Modal loading or disabled dialog buttons/fields prevent repeat taps during an operation; prior enabled states are restored, completion is dispatched only to a still-live Activity and showing dialog. Disk writes can finish after destruction but no stale UI is updated. Memory store locks and readback checks remain unchanged. No recurring work, timers, polling, automatic search or new dependencies. Local save is still explicit. Live UTF-16 counters for roleplay slots, research, context preview and memory title/body. No measured latency, device render or Android build verification. Other editor flows are unchanged.

References: https://developer.android.com/reference/kotlin/android/os/StrictMode ; https://developer.android.com/reference/android/util/AtomicFile ; https://developer.android.com/design/ui/mobile/guides/foundations/accessibility ; CAI Tools feature listing https://chromewebstore.google.com/detail/cai-tools/nbhhncgkhacdaaccjbbadkpdiljedlje (context and customization ideas, no code copied).
