# Portable memory backup (CCMX)

Roleplay Toolkit opens a private native transfer screen with manual export and import. Android document picker selects the destination or source. The file contains all Memory Bank profiles (not global roleplay slots, character cards, account, or remote chat history). Export uses a snapshot at the time of picker result. Plaintext warning is shown. CCMX v1: 12-byte header (magic/version/length), SHA-256 digest, bounded existing CCMB payload, strict EOF. Digest detects corruption, not malicious replacement. Merge preserves existing normalized profile/title keys, distinguishes same-body duplicates from conflicts, and refuses overflow of the 96-entry bank. Preview counts require confirmation; optimistic comparison under the store lock rejects a changed local snapshot. No overwrite or silent truncation. IO runs through the existing one-shot manual editor helper. Provider write/close is checked, but no provider readback or atomic external write is guaranteed; cancellation after creating a document may leave an empty/partial file. No new permissions, automatic cloud upload, recurring backup, or model training.

Design references: Android Storage Access Framework https://developer.android.com/training/data-storage/shared/documents-files ; SillyTavern MemoryBooks https://github.com/aikohanasaki/SillyTavern-MemoryBooks/blob/main/userguides/Memory_Books_AI_Reference_Manual_en.md ; CharMemory backup https://github.com/bal-spec/sillytavern-character-memory/blob/master/docs/getting-started.md ; community discussion https://www.reddit.com/r/CharacterAI/comments/1y1ethz/backup_chats/ .
