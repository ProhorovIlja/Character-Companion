# Mandy AI — foreground native inference diagnostics

The native bridge now returns eight numeric measurements on successful end-of-generation: evaluated prompt tokens, generated non-EOG tokens, retained message count (including system and newest user), fitting attempts, and monotonic wall-clock nanoseconds for template/token fitting, context initialization, prompt evaluation and generation. The generation interval includes sampler initialization and callback overhead. The timings exclude model verification/loading, storage operations and other Kotlin/UI overhead; they are not end-to-end latency or isolated CPU/GPU benchmarks. Zero-duration intervals are permitted. Counts are validated in Kotlin against the request bounds before exposing a successful result. Native failures return an exception; strict UTF-8/text validation must also succeed. Completed retries do not run inference or invent measurements. Android workspace displays ephemeral measurements after the reply is committed and the workspace refreshed. No transcript, diagnostic file, upload, telemetry, polling, scheduled tasks or background benchmark. No new dependency or permission. JNI symbol nativeGenerateV3 changes return contract, so rebuild native and Kotlin binaries together.

Cache decision: the pinned llama.cpp header (dbaf582af41941ebbfc4384fb9fa1b40dff7a510) exposes memory sequence removal and recurrent/hybrid architecture queries. However upstream server checkpoint handling differs for recurrent/hybrid and sliding-window models. Partial sequence removal may fail, and positions/state must be validated before any reuse. This iteration deliberately retains a fresh context per turn rather than adding an unvalidated cache to the Qwen-focused runtime. Next cache work should compare full-prefill baseline with architecture-specific checkpoint/prefix strategies on real supported models, invalidate on changed model/context/config or failed decode, never share conversation cache across accounts, and release on memory/lifecycle constraints. No cache optimization is claimed.
