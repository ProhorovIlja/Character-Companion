# Mandy AI — foreground model residency

The independent Android workspace now retains at most one verified EmbeddedLlama model while the activity is resumed. ResidentModel serializes access, reuses the same engine for matching verified model metadata, closes a different model before verification/loading, and releases on any verification/admission/generation failure or cooperative cancellation. Explicit Release loaded model uses the existing serialized workspace worker, preserving the draft. onPause requests cancellation and queues release behind the current foreground operation; no new inference may be started from the paused activity. This is lifecycle cleanup, not scheduled work. A native load or decode that does not cooperate promptly may delay release. No background model preload, timers or automatic model selection.

Integrity decision: full SHA-256 verification remains on every use, and the normal conservative model admission check remains unchanged even for a resident model. This preserves the previous integrity gate but may reject reuse because model pages already occupy RAM. Refusal releases the model so a later explicit retry can try again. No claim that rehash is eliminated or that mutable files are protected from a concurrent write race. Assumes app-private immutable GGUF storage and cooperating import code. Internal openVerified is used only after full verification. New generation creates a fresh native context/sampler; no KV cache reuse, conversation prompt retention or cross-account resident engine sharing. Legacy lower-level calls continue to load/close per turn. Failed user turns retain existing pending retry state; already completed retries need no engine.

Validation: 26 new JVM checks using the existing versioned JNI bridge and test-only llama fixture, real local synthetic GGUF-header files, including object identity reuse, switching and explicit release, reentrant call rejection, failed admission, cancellation before and during inference, tampered/missing model rejection, fresh context and reopen. Existing 18 durable-turn assertions recompiled and passed. Exact ResidentModel, ResidentModelSmoke, EmbeddedLlama and EmbeddedChatTurn source verified by Git blob hashes. Android Activity wiring not SDK compiled; lifecycle cleanup, peak RAM, battery and speed on actual Pixel 8a unmeasured. Host script updated; equivalent two suites executed independently. No real model or hardware performance result, no APK/EXE, no new dependency, no Windows change.

Manual host reproduction: scripts/test-embedded-jni-host.sh (Linux, JDK, Kotlin compiler, C++ compiler; fixture only).
