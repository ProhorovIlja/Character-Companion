# Mandy AI — independent bilingual Whisper bridge (source preview)

The Android native PCM foundation now has a corresponding offline ASR adapter: EmbeddedWhisper accepts a caller-owned 16 kHz mono PCM16 buffer, explicit EN/RU language, trusted model path and expected SHA-256, and 1–8 CPU threads (default 4). It verifies the file with a bounded buffer, rejects non-regular files and models over 2 GiB, requires a multilingual Whisper model even for English, converts signed samples to float using bounded JNI copy chunks, runs greedy transcription with translation/automatic language detection/previous decoder context and print flags disabled, and returns bounded strict UTF-8 text (max 16000 UTF-16 units). The native context is released after each call. No network, disk audio recording, Google services, third-party Java dependency or silent fallback. Hash verification is not publisher authentication or race-proof against concurrent replacement; use a trusted app-private immutable file. Caller must clear PCM and serialize heavy inference with the existing dialogue engine. No model importer, memory admission, voice-activity detection, noise removal, streaming recognition, UI integration or auto-send here. Cancellation is checked before/through verification and after the native call; it cannot yet interrupt whisper_full or model loading. Temporary transcript bytes are cleared best-effort in Kotlin, not guaranteed erasure of native/runtime buffers. Silent audio may still produce hallucinated text; silence rejection and real audio validation are required before connecting Send.

Standalone CMake source pins whisper.cpp c1a24047871444999b79f5e8612828f45881ae12 (exact upstream header and CMake inspected). A separate build directory is deliberately used rather than adding two different GGML source trees to the existing llama CMake project. Static dependencies, restricted export map, CPU-only initial configuration and 16 KiB ELF load alignment are intended to isolate the libraries. Isolation, actual linkage and Android ABI compatibility are NOT yet validated. This is not included in the Gradle APK build; do not manually bundle an unverified library or a test fixture. Existing Android UI and llama build stay unchanged.

Manual host regression (Linux/JDK/Kotlin/clang): bash scripts/test-embedded-whisper-host.sh

Manual real native build candidate, only after explicitly preparing a clean pinned checkout, NDK r29 and CMake 3.31.6, with a fresh separate build directory:

    cmake -S app/src/main/cpp/whisper -B <speech-build-dir> -DCMAKE_TOOLCHAIN_FILE=<ndk>/build/cmake/android.toolchain.cmake -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-29 -DANDROID_STL=c++_static -DMANDY_WHISPER_DIR=<pinned-checkout>
    cmake --build <speech-build-dir> --target mandy_whisper --config Release
