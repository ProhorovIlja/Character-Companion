# Mandy AI — bounded context suffix refinement

Replaces geometric history reduction with bounded binary search over older-message removal boundaries. First render/tokenize the entire bounded candidate once. If it fits, keep it unchanged. Otherwise candidate starts are later user messages, including the newest user message. Binary-search the boundary, reserving output tokens on every attempt. Preserve the exact last successful token array, so a later failed probe cannot overwrite the selected prompt and no final re-render is required. System message (including supplied identity and selected memory) and newest message are never cut. Saved history is unchanged. Cancellation is checked between attempts. Maximum nine template/tokenizer attempts at the existing 201-message cap. Additional scratch storage is at most 8192 tokens.

This finds the longest fitting eligible suffix when fit is monotonic. Real template rendering/tokenization can be nonmonotonic; binary search can miss a longer fitting suffix. Every accepted result is explicitly tokenized and within budget, and if no tested suffix fits, fail closed. Not an exact global optimizer for arbitrary templates. The Kotlin 12,000 UTF-16 prefilter, model training-context limits, existing template support and output caps remain. No summarization, KV-cache reuse, real benchmark or additional dependency.
