# Mandy AI — native character memory and relationship context (2026-11-24)

Adds account/character-scoped NativeCharacterMemory, persisted in versioned private files with atomic replacement, file sync and optimistic revision checking. A character has one reviewed relationship description, one pinned note and up to 32 individually editable memories. Default strangers; seven stage labels, no forced progression. Multiple chats share this state. Native Send/Retry now resolves the profile by actual conversation key and combines its identity with reviewed context from that character, based on the pending message. Pinned and relationship notes are added when room permits; at most four lexical matches ranked by shared distinct words (case-insensitive Unicode, length >=3) follow. The core identity is not truncated. Optional context may be skipped when the current 8,000 identity / 12,000 combined UTF-16 budget is insufficient. This is not token-aware, semantic embedding retrieval, automatic summarization or learned relationship assessment. Notes are user-reviewed; the descriptive prompt does not guarantee prompt-injection resistance. This new store is a current-state editor, not a port of the evidence-backed Python relationship revision history. No auto-escalation or background extraction.

The Android preview adds an explicit Memory & relationship editor for the selected character. It supports replacing and removing notes, selecting a stage, and saving via the existing serialized disk worker. No automatic updates, no cross-device sync, no cloud upload, no new dependencies. Data remains plaintext in the app sandbox. Limits (800 relationship, 1,200 pinned, 32 x 400 memory text units) are provisional. One writer per account required; no cross-process locks, directory fsync or guaranteed crash durability. Corrupt memory records fail closed and can prevent workspace loading; recovery UI not yet implemented. Native Android activity remains SDK-uncompiled and English-only. No actual GGUF inference, device tests, APK or EXE.

Verification: exact NativeCharacterMemory.kt and NativeCharacterMemorySmoke.kt compiled with NativeConversation.kt and passed 23 counted assertions using real temporary files (default, persistence, revision conflicts, account/character isolation, Russian matching, selection, correction, malformed records, context budgets). Existing EmbeddedChatTurn regression modified to exercise memory-enabled path, compiled and rerun against the production JNI bridge and deterministic fixture; 15 checks passed. The fixture does not establish neural recall quality or actual prompt-template behavior. Host script includes both suites; individual equivalent commands were executed. No scheduling or workflow dispatch.
