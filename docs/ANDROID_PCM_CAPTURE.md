# Mandy AI — standalone Android PCM capture foundation

This increment adds an independent microphone capture primitive for future embedded whisper.cpp or sherpa-onnx recognition. Current UI still uses the existing on-device SpeechRecognizer path; no audio is captured by this new source until an explicit foreground caller integrates it. No Google services, network, model downloads, background service, scheduled operation or new dependency. Uses the existing RECORD_AUDIO permission; permission request and lifecycle cancellation remain the caller's responsibility. The adapter tries mono PCM16 at 16, 48 and 44.1 kHz, verifies the initialized format and recording state, then reads approximately 20 ms chunks on the explicit worker. It stops at the caller's requested stop or the sample duration cap (1–180 seconds), throws on read error/cancellation and releases the recorder. Driver-level blocking reads are cooperative and not a hard wall-clock timeout; audio focus, route changes, device-specific capture effects and cancellation latency require Android testing. It does not auto-send or transcribe. No UI wiring in this increment.

PcmSpeechBuffer is a pure Kotlin, bounded, chunk-independent mono downsampler using an area-weighted box filter, integer rounding away from zero (consistent with the existing Windows Pcm16Resampler's mono path). It accepts 16–96 kHz PCM16 and emits 16 kHz PCM16, including partial final sample. At 180 seconds the final PCM array is at most 2,880,000 shorts (5.76 MB), with transient copies during growth/finalization. No temporary recording file. It clears owned sample arrays on close and clears the microphone chunk; caller owns returned samples and should clear after recognition. This is best-effort memory cleanup, not guaranteed zeroization of all runtime or system audio buffers. Box resampling is a lightweight baseline, not studio-quality anti-aliasing; compare actual speech quality and performance against platform resampling or higher-quality resamplers before changing. No stereo or upsampling, no VAD, no voice activity streaming, no full duplex or local ASR yet.
