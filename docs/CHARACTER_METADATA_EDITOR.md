# Character metadata editing
Character Studio now supports explicit add, edit, delete, move up/down and copy for ordered alternative greetings and tags; greetings can still become the primary greeting. Source notes can be edited or cleared. Shared editor uses a bounded input length, private IME flags and stale-draft checks. New list items must be nonblank and valid UTF-8 encodable text; imported existing items are not automatically rewritten. Previews are 80 Unicode code points; no storage format changes. Existing CCDR/CCBK compatibility is maintained for represented fields, not full CCv3 fidelity.
24 focused JVM checks passed on exact new policy/test and existing draft policy/codec with a LorebookPolicy.MAX_CHARS stub. UI and Android compile remain untested.
