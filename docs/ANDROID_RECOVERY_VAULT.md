# Mandy AI — protected local recovery vault (experimental)

This increment stores an explicitly supplied continuity recovery secret in a 68-byte local record: ASCII MANDYV01 (8), provider-generated 96-bit nonce (12), AES-GCM ciphertext and 128-bit tag (48). Additional authenticated data is the magic followed by the canonical account UUID. The device wrapping key is distinct from the root secret and derived history/manifest keys. The local vault is not a portable backup. RecoveryVault requires an existing or explicitly provisioned wrapping-key provider and uses a cooperative file lock, process-local mutex, private temp file, file fsync and atomic move. It rejects existing records (even corrupt), malformed recovery code, wrong account, missing records, wrong key, authentication failure and extra/truncated bytes. Loading never generates a new wrapping key. Only explicit install of a matching recovery code can create a wrapping key if absent; no automatic root generation or destructive reset. A missing file can be explicitly installed again, so future UI must validate a recovery code against known ciphertext when restoring existing data. No recovery overwrite/delete API; a verified repair flow remains necessary. Directory fsync, crash orphan cleanup, nonce usage accounting and key lifecycle remain outstanding. Assumes trusted private directory and cooperating writers. Immutable strings and provider copies cannot reliably be erased.

AndroidRecoveryVault uses the platform AndroidKeyStore AES-256-GCM key provider and noBackupFilesDir. Randomized encryption is required. The platform decides whether keys are hardware-backed; no StrongBox or biometric requirement is claimed. Key material is not exported by the adapter. No new dependency or permission. No UI or backup operation wired yet. No actual user secret created or stored. The Android source is not SDK-compiled and hardware-backed key availability is not tested on the target LineageOS device.

Research: Android Keystore KeyGenParameterSpec.Builder docs (https://developer.android.com/reference/android/security/keystore/KeyGenParameterSpec.Builder); flutter_secure_storage (https://github.com/juliansteenbakker/flutter_secure_storage); secure-store-kt (https://github.com/Kosikowski/secure-store-kt); OWASP Android Security Masterclass (https://github.com/OWASP/Android-Security-Masterclass); Windows DPAPI ProtectedData (https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata); Git Credential Manager and its fork documentation (https://github.com/git-ecosystem/git-credential-manager/blob/main/docs/credstores.md and https://github.com/WrenParker/Git-Credential-Manager-Core/blob/main/docs/credstores.md); windows-native-keyring-store (https://github.com/open-source-cooperative/windows-native-keyring-store). These are design references, not copied implementations. Direct platform primitives are sufficient for the single fixed-size root record; adding a general-purpose storage framework now would expand dependency surface. Windows CurrentUser DPAPI is the next candidate, not implemented in this increment.

Validation: Kotlin/JVM compiled exact RecoveryVault.kt and RecoveryVaultSmoke.kt with existing NativeConversation.kt and ContinuityKeys.kt. First compile failed on a Long/Int comparison; corrected before publication. 29 assertions passed using real temporary files, JCA AES-GCM and a fixture software key. Includes absent-record behavior without key generation, wrong account, wrong/missing key, tampering of magic/nonce/ciphertext/tag, truncation, extra bytes, reinstall refusal, preservation, reopened vault, and account-bound authentication even when test wrapping key is shared. No Android SDK/NDK, Windows SDK or real device tests. No APK, EXE, cloud upload, scheduled tasks or workflow dispatch.

Manual reproduction: kotlinc NativeConversation.kt ContinuityKeys.kt RecoveryVault.kt RecoveryVaultSmoke.kt -include-runtime -d smoke.jar; java -jar smoke.jar (use source paths from app/src/main/java/dev/caicompanion/app and tests). Fixture secrets must never be used outside tests.
