# Character Context and research
Inspired by SillyTavern WebSearch, Data Bank, World Info, summary and memory tools (https://github.com/SillyTavern/Extension-WebSearch ; https://github.com/SillyTavern/SillyTavern-Docs/blob/main/Usage/Characters/data-bank.md ; https://github.com/SillyTavern/SillyTavern-Docs/blob/main/extensions/Summarize.md ; https://github.com/ember-and-ink/cairn-memory ; https://github.com/bal-spec/sillytavern-character-memory). Official Character.AI creator memory guidance: https://support.character.ai/hc/en-us/articles/50609303987099-6-Refining-and-Testing-your-Character . Community recap advice: https://www.reddit.com/r/CharacterAI/comments/156lwmk . These are architectural references, not imported code.
Roleplay toolkit now builds a reviewable editable context packet from explicitly selected saved slots and optionally pasted external research. No silent truncation: total 16,000 UTF-16 units including headers. Research is labeled reference material, not instructions; this is not a guaranteed prompt-injection defense. The browser launcher accepts only manually entered queries up to 512 UTF-16 units, fixed HTTPS DuckDuckGo/Google/English Wikipedia providers, and percent-encodes queries. It never reads or appends private notes, scrapes pages, invokes account APIs or sends chat messages. User must read results, paste findings, review and copy context into chat. All three existing toolkit entrypoints inherit the additions. No model training, autonomous search, per-character memories, automatic retrieval, new dependencies or scheduling. 26 focused JVM checks executed on exact policy and existing RoleplayToolkit; Android compilation, UI, browser and account tests not performed.
