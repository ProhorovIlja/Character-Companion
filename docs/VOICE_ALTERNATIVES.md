# Dictation alternatives
After final recognition, the first valid fitting alternative remains the default. The new native action exposes up to five distinct valid edits from the provider, with bounded Unicode-safe labels. Choosing another result replaces only the previous speech edit from its original selection. Undo restores the pre-recognition text and selection. Manual edits invalidate the choice; stale dialogs cannot overwrite a changed draft. Alternatives remain only in memory across configuration changes, never disk or saved Bundle. No extra provider request, recording, automatic send, or added dependency.
20 executable JVM assertions passed on exact VoiceDraftPolicy, VoiceAlternatives and VoiceAlternativesSmoke sources. Android integration and real device/provider behavior still require testing.
References: https://developer.android.com/reference/android/speech/SpeechRecognizer ; https://developer.android.com/reference/android/speech/RecognitionListener ; https://github.com/futo-org/voice-input ; https://github.com/notune/android_transcribe_app ; https://github.com/minburg/outspoke . External providers are research candidates, not bundled or tested. No external source copied.
