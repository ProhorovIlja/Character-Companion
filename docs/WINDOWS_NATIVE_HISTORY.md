# Native Windows history source preview

Adds LocalHistory.cs, a native C# local SQLite store sharing the existing v1 Android/Python schema and UUIDv5 reply identity. Uses Microsoft.Data.Sqlite 10.0.15 (published 2026-11-10; maintained .NET 10 line, not the newer major 11.0). Direct SQL, no ORM. Explicit local absolute database path, private cache, pooling disabled, five-second busy timeout, foreign keys, WAL/FULL, non-deferred write transactions, account and schema guards, canonical IDs and bounded Unicode. Append/retry and reply commit enforce idempotence, chat ownership and latest user checks; cursor pages use the existing composite index. No destructive migration, file reset, network, schedule or background process. Caller must use a trusted private local path and serialize access to each instance on a foreground-request worker; not safe for simultaneous callers or untrusted database files. SQLite stores plaintext locally. No automatic sync, wire import/export, profile/draft store or WPF hookup in this increment.

Manual source smoke project: dotnet run --project windows/HistorySmoke/CharacterCompanion.HistorySmoke.csproj
The smoke program exercises real temporary SQLite files when executed, including retry, conflict, scoping, pagination, stale reply, reopen and schema/account refusal. It has NOT been compiled or executed. The local environment has no .NET SDK. Package restore, native SQLite deployment, cross-platform byte/UUID parity and actual Windows runtime testing remain required; no EXE or measured performance claim. Package pin is a new dependency with transitive native assets; inspect restore graph, licenses and audit output before distribution. Existing browser and Android code unchanged.

References: https://www.nuget.org/packages/Microsoft.Data.Sqlite/10.0.15 ; https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/transactions ; https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/connection-strings ; https://www.sqlite.org/wal.html ; https://www.sqlite.org/pragma.html#pragma_synchronous ; https://www.sqlite.org/rowvalue.html . Existing schema and behavior drawn from shared/history_store.py and AndroidConversationStore.kt. No external implementation copied.
