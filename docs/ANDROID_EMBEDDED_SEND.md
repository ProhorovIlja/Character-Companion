# Mandy AI — experimental embedded Send/Retry (2026-11-24)

EmbeddedChatTurn binds the existing character library, persisted pending message, history protocol, verified model library and direct JNI engine. Profile identity comes from the exact character/chat key. A real model is opened lazily only when inference is needed, then closed in use; completed retries return saved replies without model loading. No network fallback. The Android workspace adds an experimental model picker, explicit trust confirmation, Send/Retry, pending-state discard confirmation and Stop control, only for builds explicitly configured with mandyLlamaDir. The default build cannot send. Models are inventoried on explicit workspace operations, including Refresh model inventory after import. No automatically selected model or background task. The preview uses the existing serialized worker and render-thread ticket checks; updates are throttled during active generation, no timer. On failure after saving the draft, reload persisted state, not an uncommitted partial answer. If reload fails, require workspace reopen. Leaving the screen requests cooperative stop.

Validation: exact EmbeddedChatTurn.kt and EmbeddedChatTurnSmoke.kt compiled with existing production Kotlin classes and exercised using the previously compiled production JNI bridge with its deterministic test double, JDK -Xcheck:jni. 15 counted assertions passed: profile identity, stream-to-history commit, deterministic reply, cancellation, retry, newer draft, wrong ticket, missing model, isolation, completed retry after model file removal. Actual filesystem used for profiles/drafts/models; history is in-memory fixture. No real neural inference or Android SQLite lifecycle validation. The host test script now includes this suite. Android activity and Gradle flag source reviewed, not compiled against SDK. No APK/EXE.

Design choices and limitations: experimental flag is build-time, not a release certification; every new reply rehashes and opens/closes model weights, favoring resource cleanup over speed until device measurements. A large model may exhaust memory or crash; model trust and compatibility remain caller responsibility. Cancellation is cooperative; final commit race remains. Current context limits and built-in chat template restrictions unchanged. English-only preview, no native voice/relationship/memory integration yet. Real SDK/NDK, llama.cpp checkout and licensed model tests remain mandatory before declaring a working companion. No new workflow or dispatch.
