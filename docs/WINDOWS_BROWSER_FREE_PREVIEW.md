# Browser-free native Windows preview

This opt-in standalone WPF project links the existing native LocalHistory, LocalInferenceClient and LocalChatTurn production sources directly. It does not reference CefSharp, NAudio, the legacy App.xaml startup or the browser client. The old application remains unchanged. The new project uses only the existing Microsoft.Data.Sqlite 10.0.15 dependency and WPF/.NET 10. No model/server download or launch, updater, monitoring, scheduled task or background service. All disk and inference work is awaited after explicit user interaction. Choose a trusted, app-private local folder on the desired SSD; do not place the database on a cloud/network filesystem. Choose an empty folder for Create, or an existing preview workspace for Open. A local profile descriptor and SQLite store persist stable account/device/character/chat IDs and character identity. A cooperative exclusive file lease prevents two preview instances opening the same workspace. Incomplete workspace creation is refused on reopen; no automatic cleanup or destructive recovery. This is not hardened against malicious local file replacement and metadata is not encrypted. Use only trusted folders. Local history is plaintext.

The preview has one character and one chat per workspace, explicit trusted local server alias/port/key entry (key not stored), latest 50 messages displayed in a recycling WPF ListBox, a multiline composer, Send/Stop, Refresh, and retry of the newest unresolved user message across reopen. Input is disabled during active requests; closing waits for the explicitly requested operation to settle after cancellation. Only complete persisted replies are displayed, no streaming preview yet. Draft edits before Send are not durably stored; if a request fails before user persistence the draft remains while the window stays open. A history read failure disables further Send until Refresh. No character editing, multi-chat browser, offline dictation, TTS, recovery UI, encrypted sync, final theme or Russian UI localization in this preview. Russian and English text input is supported by the underlying contract; UI labels currently English. Legacy client remains available separately.

Manual build from repository root, on Windows with .NET 10 SDK and trusted NuGet restore sources:
    dotnet run --project windows/Mandy.NativePreview/Mandy.NativePreview.csproj
After manually starting the trusted llama.cpp loopback server (see WINDOWS_LOCAL_CHAT_BASELINE.md), enter its private key and alias. No cloud fallback. Before distributing, compile both the native HistorySmoke project and WPF preview, audit restored dependencies, test cancellation/reopen and actual CUDA inference.

This is an uncompiled source preview, not a release.
