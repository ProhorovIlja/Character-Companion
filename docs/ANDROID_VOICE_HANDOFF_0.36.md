# Android 0.36.0-rc1 — private focused-editor handoff

Both embedded flavors can request a private voice draft from the toolbar. On a recognized first-party chat route, the editor offers **Insert into focused chat and return**. Focus the message composer first, dismiss the keyboard if needed to reach Voice, dictate and review. The app uses the renderer's standard Android input connection exactly once, only on the same chat route, with an already-focused ordinary multiline text field. No JavaScript bridge, clipboard access during handoff, automatic focus selection, page-text inspection or send action. New top-level loads, URL changes and renderer termination invalidate the handoff. If unavailable, the draft reopens for editing or explicit copy; no attempt is made to send to a different field. A positive input-connection response is not a guarantee of website-side insertion. Real WebView/GeckoView focus and composer behavior must be tested on the phone. Browser-owned Custom Tabs still require explicit copy/paste; they do not expose their private editor to the app.

The speech recognizer now rejects duplicate/stale external results and only starts local speech on a foreground tap after microphone permission. Collapsed UTF-16 cursor selections snap after a surrogate pair instead of deleting it. No unsent transcript saved in settings or an instance-state Bundle; process death can still discard unsaved text. Export and copy remain deliberate actions.

Browser-owned sign-in retains the selected compatible browser package, not credentials. If that browser disappears, the app refuses to switch silently to another browser's cookie jar; an explicit change action uses the current default. This does not implement a Character.AI OAuth callback or native session import.

QA: both embedded engines; valid/unsupported URL; focused textarea and no focus; leave/reload chat while dictating; cancel, rotation, stale speech callback, permission grant, emoji selection; Custom Tab default change and unavailable provider; real device verification pending. No auto-send, additional dependencies, or automated build triggers.
