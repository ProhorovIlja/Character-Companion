# Offline speech model library

The existing digest-addressed model importer now supports explicit GGUF and Whisper GGML formats using the same bounded streaming copy and verification path. Existing GGUF filenames and default directory stay unchanged. The new speech directory is mandy-speech-models-v1 under noBackupFilesDir, with SHA-256 .bin names and a per-file 2 GiB ceiling. The model screen adds an explicit Whisper file picker and separately labelled inventory. No storage permission, automatic download, persistent URI grant or activation. The user-selected document provider may itself be remote. The picker can import files without Google services if a suitable provider is installed. Models are copied into app-private storage. Imported files are not included in the APK.

Whisper header precheck follows the pinned c1a24047871444999b79f5e8612828f45881ae12 whisper_model_load and GGML_FILE_MAGIC: little-endian magic 0x67676d6c, ten positive dimensions/counts, nonnegative ftype and matching audio/text state. It is a preliminary format check, not a complete model validator, license validation or proof of multilingual capability. Native runtime must separately verify model compatibility, expected digest and multilingual support before execution. Use known trusted models only. Baseline candidates: multilingual base/small and quantized variants, subject to actual Pixel 8a testing. No speech runtime selection, VAD, model activation or microphone-to-composer integration in this commit.

The existing import path uses bounded 128 KiB chunks, exact optional size/hash, fsync, atomic move, no overwrite of a corrupted digest file under cooperative single-process use, and cancellation checkpoints. Per-file size bounds are not a total storage quota; interrupted processes may leave temporary files; no deletion UI, directory fsync or malicious concurrent-file protection. The generic library now constrains maxBytes to the supported format ceiling. Default GGUF path and 8 GiB limit unchanged. No third-party implementation copied.

Validation: actual Kotlin/JVM compilation and execution of 19 new synthetic Whisper header/file assertions and 17 existing GGUF regression assertions, 36 total. Checked exact compiled core/test Git hashes. Android SAF and activity source not SDK compiled. No real speech weights, neural recognition, APK, Windows change or measured performance. Manual host tests: compile NativeModelLibrary.kt with tests/SpeechModelLibrarySmoke.kt or tests/NativeModelLibrarySmoke.kt separately using kotlinc -include-runtime, then execute the resulting jar.
