# Mandy AI — evidence-bound memory extraction

MemoryAssessment selects at most one proposed memory from the latest completed user/character turn. The model is prompted to return SKIP or REMEMBER followed by an exact contiguous single-line excerpt of the user's dialogue. The core validates the excerpt against the actual persisted user message, bounds its length, rejects invented or assistant-only text, and checks the existing memory revision and exact latest completed evidence again on approval. Saved notes are prefixed User said: and participate in existing character-specific lexical retrieval across chats. Exact duplicate notes are skipped. A full 32-entry memory store is left unchanged rather than silently evicting older entries. No changes are made without approval.

Android experimental workspace exposes Review memory from dialogue and shares the existing model picker, foreground assessment worker, cancel control and evidence review with relationship assessment. It uses the existing embedded runtime, no remote fallback. The review shows the proposed excerpt and complete dialogue, then approves or rejects it. No automatic extraction, scheduled activity, network access or background task. No schema change; existing memory editor can correct or delete retained notes.

Validation: exact MemoryAssessment.kt and MemoryAssessmentSmoke.kt were compiled and executed on Kotlin/JVM with existing production history, workspace, memory and relationship classes; 25 counted checks passed with real temporary files and in-memory history/model fixtures. Covers incomplete dialogue, malformed output, fabricated text, assistant-only text, cancellation, revision/evidence conflicts, character isolation, duplication, full capacity, persistence and retrieval. Model relevance, sensitive-content selection, quote context and real semantic recall are not guaranteed: a verbatim substring can still misrepresent its context, so review remains required. Prompt-level instructions are not a secure secret detector. Accepted notes do not persist source message IDs separately; proposals are transient. Current UTF-16 limits and 384 assessment output tokens are provisional. Android UI and Gradle/NDK remain uncompiled here; no real-model inference or APK/EXE. Existing host regression script extended, not run in its entirety. No workflow dispatch.
