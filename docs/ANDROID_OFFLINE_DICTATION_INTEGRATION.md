# Experimental independent offline dictation integration

Adds an explicitly selected Whisper path to the existing Android native workspace when MANDY_WHISPER_PREVIEW is enabled and the user has imported a model. It offers a trusted model confirmation and EN/RU choice, records PCM via AndroidPcmCapture, normalizes in memory, runs EmbeddedWhisper on the serialized explicit workspace worker and feeds the same NativeDictation draft insertion and persistence path as the existing on-device recognizer. No fallback, network, Google speech service, background microphone, timer or scheduled operation. The system on-device recognition option remains separate and unchanged in intent.

The experimental Whisper option releases resident text-model memory before recording and uses the existing conservative text-model admission estimator before capture and recognition (not a measured ASR-specific estimator). Stop requests capture completion; cancel invalidates the session and discards results; natural cap completion never sends. No auto-send for this preview: review the draft and send manually because neural VAD and real recognition accuracy remain unvalidated. Session-specific atomic phase and one-shot guard prevent reusing a cancelled recording. Captured PCM is cleared in finally on success/failure/cancellation. Kotlin/native buffers and OS capture buffers are not guaranteed erased. UI token and draft/ticket checks reject stale callbacks; lifecycle cancellation is cooperative, may be delayed by blocking AudioRecord reads or Whisper computation. Existing serial executor keeps a later requested operation from overlapping the previous one. No partial transcript, route handling, VAD, TTS, simultaneous chat/ASR or actual hardware performance claim.

Research: https://developer.android.com/reference/android/media/AudioRecord (blocking reads/resource lifetime); https://github.com/ggml-org/whisper.cpp/blob/master/examples/cli/README.md and https://github.com/ggml-org/whisper.cpp/blob/master/README.md (no-speech and Silero VAD options). Keep review mandatory until real EN/RU speech and silence validation. No third-party code copied, new dependency or model weights.

Validation: actual new Kotlin/JVM OfflineSpeechSession smoke test passed 31 assertions using capture/recognition doubles, including explicit Stop, one-shot guard, cancel before/during capture or recognition, invalid output and PCM cleanup on failure. Existing NativeDictation 27 checks and EmbeddedWhisper 59 JNI fixture checks rerun successfully (117 total counted assertions). Exact new core/test hashes matched tested files; Android activity changes are source only, not compiled or run because SDK/NDK are unavailable. No real model inference, microphone test, APK, EXE, Windows change or hardware benchmark. Manual host reproduction: kotlinc app/src/main/java/dev/caicompanion/app/OfflineSpeechSession.kt app/src/main/java/dev/caicompanion/app/NativeConversation.kt tests/OfflineSpeechSessionSmoke.kt -include-runtime -d speech-session.jar ; java -jar speech-session.jar.
