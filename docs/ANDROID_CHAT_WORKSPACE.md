# Mandy AI — native workspace and recoverable drafts (2026-11-24)

NativeChatWorkspace is a Kotlin/JVM foreground component for the independent Android chat. The selected character/chat ID pair is persisted; each account/device/character/chat has a separate draft and pending-send record. Explicit prepare allocates a stable UUID, atomically moves the draft into pending state, and allows a new draft without overwriting the pending message. Explicit retry uses the same UUID and the existing NativeConversation idempotence contract. Successful completion clears only the matching pending record, preserving a newer draft. Discard pending never deletes any already committed history. No auto-resend after restart.

Session tickets change on selection, including reopening and selecting the same chat. Generation cooperatively cancels on a stale ticket; each output callback includes the originating ticket and UI must recheck it on the render thread. A switch concurrent with final DB commit can still leave a completed reply in the original chat. One in-flight turn per workspace, no lock held during generation. Caller must maintain exactly one live workspace instance per account/device; this is not a cross-process lock.

Private local files use bounded versioned binary records, file sync and atomic replacement without unsafe fallback. Read rejects malformed/trailing content and incorrect key. No directory fsync or power-loss durability guarantee. No encryption, backup or cloud replication; Android wrapper uses noBackupFilesDir. These are separate device-local draft records, not history protocol events. No automatic file cleanup or retention schedule. Provisional 16,000 UTF-16 units each for draft and pending text, 100,000 bytes per record. Persist edits on an explicitly initiated worker, not per-keystroke fsync on the UI thread. Do not place files in public GitHub or unencrypted Drive.

AndroidChatWorkspace wires sessions to AndroidConversationStore and LocalChatProvider in source. Caller supplies character identity, stable account and device IDs and a trusted local model endpoint. No character library/editor, real chat screen, native engine, authentication or cleartext policy change in this revision. Android-specific adapter still requires compilation and device tests.

Validation: exact NativeChatWorkspace.kt and NativeChatWorkspaceSmoke.kt compiled with existing NativeConversation.kt on Kotlin/JVM and JDK 21. 20 counted checks passed using real temporary files, a simulated provider and in-memory history. Covers reopen, namespaces, pending ID retry, newer draft preservation, stale selection, switch during generation, Unicode limits, corrupt records. No new APK or EXE. No scheduled jobs.
