# Character Companion — только Android

**v0.3.0, исходный проект от 22 ноября 2026 года.** Независимый клиент сайта `https://character.ai/` на Kotlin. Без Windows, без неофициального API и без доступа к паролям. Лицензия MIT; не связан с Character.AI.

**Реальный статус:** опубликованы исходники, ресурсы, документация и тесты. Проверки без Android SDK завершены: **9 структурных тестов + 49 Kotlin-проверок**. В этом окружении нет Android SDK/Gradle, поэтому **APK не собирался и на телефоне не тестировался**. Авторизация, чаты, звонки, Google/Apple OAuth и работа сайта требуют реального тестирования; нельзя утверждать, что всё это уже работает.

## Реализованные возможности

- Современная тёмная графитово-золотая оболочка с адаптивной иконкой, прогрессом загрузки, ошибками и крупными зонами нажатия; учтены системные панели Android 15/16.
- Навигация, домашняя страница, назад/вперёд, обновление, отправка ссылки, открытие в системном браузере. Долгое нажатие на «Ссылка» копирует адрес; долгое нажатие на «Обновить» очищает кеш.
- Сохранение до 100 закладок. В них не сохраняются URL провайдеров авторизации, фрагменты и неизвестные query-параметры, содержащие потенциально чувствительные данные.
- Фильтр известных рекламных/аналитических доменов: 21 базовое правило, 20 дополнительных правил в экспериментальном строгом режиме, собственные блокировки и исключения. Блокировка запросов service worker при поддержке движка. Это не гарантирует исчезновения всей рекламы.
- Управление сторонними cookie, доступом к микрофону/камере (по умолчанию запрещён), разрешением воспроизведения медиа, масштабом текста, компактностью панели и режимом десктопного сайта.
- Экономия трафика изображений (может скрыть портреты), восстановление последней страницы (по умолчанию выключено), ручная диагностика версии WebView и статистики фильтра.
- Открытие файлов через системный выбор Android, загрузка HTTPS через DownloadManager, обработка TLS-ошибок и восстановления после сбоя рендерера.
- Ручной экспорт/импорт настроек и закладок через JSON. Импорт ограничен по размеру и выполняется одной транзакцией. **Переписки, cookie, токены и пароли не экспортируются.**
- Русские и английские строки интерфейса. Сам язык сайта определяется Character.AI.

**Ограничения:** официальный API Character.AI отсутствует; Google может запрещать OAuth во встроенном WebView. Внешний браузер сохраняет собственную сессию и не авторизует автоматически встроенный WebView. Голосовые звонки могут быть доступны только в официальном приложении. Подписки и серверные ограничения не обходятся. Нет фоновых задач, мониторингов, уведомлений или запусков по расписанию.

## Сборка

Нужны Android Studio, **SDK Platform 36**, **JDK 17**, **Gradle 8.13**, **AGP 8.13.0**, **Kotlin 2.2.0**. Откройте корень репозитория, настройте Gradle, выполните Sync и `Build → Build APK(s)` либо `gradle :app:assembleDebug` с установленным Gradle. APK появляется в `app/build/outputs/apk/debug/app-debug.apk` **только после успешной сборки**. Приложение рассчитано на Android 10 и выше.

Локальные тесты без SDK: `bash scripts/test-offline.sh`. Список обязательных проверок на телефоне — [docs/QA.md](docs/QA.md). Исследования — [docs/RESEARCH.md](docs/RESEARCH.md); ограничения и безопасность — [docs/SECURITY.md](docs/SECURITY.md), изменения — [docs/CHANGELOG.md](docs/CHANGELOG.md).
