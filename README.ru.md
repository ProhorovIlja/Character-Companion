# Character Companion для Android

Независимый клиент сайта Character.AI. **Исходная версия 0.2.0, не готовый APK.** Репозиторий содержит только Android-проект; Windows-код удалён.

**Реализовано в исходниках:** тёмный интерфейс с золотистыми акцентами и иконкой, навигация и закладки, системный выбор/загрузка файлов, 21 правило фильтрации сторонних доменов, собственные правила и исключения, перехват запросов service worker, статистика блокировок, настройки cookies, разрешений на микрофон/камеру, масштаба 75–175%, компактной панели, фонового полотна и режима рабочего стола. Есть экспорт/импорт настроек и закладок без переписок или токенов, обработка ошибки загрузки, TLS-ошибок и падений рендерера WebView.

**Чего нет:** собственного API Character.AI, обхода подписок и лимитов, гарантированной блокировки встроенной рекламы, сохранения чужих чатов, сбора паролей, автоматических фоновых задач и гарантированной поддержки Google OAuth/звонков. Клиент использует официальный сайт.

### Сборка

Откройте корневую папку проекта в Android Studio. Нужны Android SDK 36, JDK 17, Gradle 8.13, AGP 8.13.0, Kotlin 2.2.0. После Gradle Sync выберите `Build → Build APK(s)`; результат при успешной сборке — `app/build/outputs/apk/debug/app-debug.apk`. Здесь **Android SDK отсутствует, поэтому APK не собирался и на смартфоне не проверялся**.

Тесты без Android SDK: `bash scripts/test-offline.sh`.

Google может запрещать вход через встроенный WebView. Для просмотра сайта через обычный браузер предусмотрена кнопка ↗, но браузерная сессия не переносится в приложение. Официальный сайт может менять поведение без предупреждения.
